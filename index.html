Comment la valeur est-elle calculée ?

Pour chaque modèle, l’estimation part de la médiane des ventes du dernier semestre couvert (hors one-offs, comme le Daytona SP3 caritatif), c’est-à-dire le niveau réel du marché. Elle applique ensuite l’élasticité prix/kilométrage mesurée sur les ventes suivies (régression log-log sur les ventes dont le kilométrage est connu ; valeur type de −0,12 à −0,40 selon le modèle si l’échantillon est trop petit), puis un léger facteur d’année (−3 %/an, plafonné) pour les modèles récents uniquement — pour les séries limitées anciennes, l’année ne pèse presque rien face au kilométrage et à la spécification.

La fourchette affichée (±15 %) traduit la dispersion réelle des ventes. Limites : échantillons faibles pour les modèles rares (Monza SP2, Daytona SP3, 812 Competizione A) ; aucune 12Cilindri Spider vendue en salle, l’estimation repose alors sur les repères du coupé ; une enchère est une tendance de marché, pas une expertise — l’état, l’historique, la couleur et les options font varier le prix.
